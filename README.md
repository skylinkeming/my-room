# 日日小屋 · Little Warm Home

依據溫暖 Japandi 風格的室內設計稿製作，以 React、Three.js、React Three Fiber 與 Drei 呈現可旋轉的 3D 小屋。

- 寢室：景觀窗與雙層窗簾、綠色雙人床、床頭燈、整面衣櫃、靠牆電腦桌椅、書櫃與閱讀角。
- 客廳：杏桃色沙發、茶几、編織地毯、正對沙發的電視與電視櫃、邊桌與收納邊櫃。
- 開放式廚房與餐廳：鼠尾草綠櫥櫃、冰箱與烤箱、櫃下燈帶、四人餐桌及編織吊燈。
- 全高中央隔牆設有實際門洞；電視櫃避開門口，保留兩側通道。

## 開發

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
```

拖曳旋轉、滾輪縮放；下方按鈕切換全屋、寢室或客廳視角。右上切換日夜，右側切換房間標籤或重設視角。支援手機版。

## 建置

```sh
npm run build
npm run preview
```

`src/House.jsx` 包含房屋與家具模型；`src/main.jsx` 負責頁面、燈光與視角操作。所有家具、木紋、布紋及窗外景觀均由程式產生，不需要外部模型、貼圖服務或 API 金鑰。場景為可互動的風格化 3D 實作，非設計稿的靜態背景圖片。
