# 日日小屋 · European Country Cottage

依照歐洲鄉村設計稿重建的 React + Three.js 互動小屋。首頁直接呈現可旋轉、縮放的 3D 模型，不使用設計稿圖片替代場景。

## 房屋與室內

- 正面石砌外牆保留，設有實際窗洞、木框分格玻璃窗與鼠尾草綠百葉窗。
- 兩側陶瓦屋簷、石砌煙囪和暖色壁爐；頂部保持剖面視角，能看見室內。
- 寢室包含雙人床、花布抱枕與窗簾、原木衣櫃、靠牆電腦桌和閱讀角。
- 客廳保留沙發、電視與茶几；廚房改為鄉村框板櫥櫃、窗下農舍水槽及開放層架。
- 客廳右側法式雙開玻璃門可開關，通往石鋪茶席露台。

## 花園

彎曲紅磚步道連接露台、玫瑰拱門和木柵門。繡球花、薰衣草與攀牆玫瑰集中在花境，中央保留草地。另有橄欖樹、木長椅、庭園小屋、藤編戶外座椅與茶几。原有日式溪流、拱橋、竹叢、枯山水與櫻花配置已移除。

花瓣、葉片、磚塊、石材與屋瓦使用實例繪製，減少大量重複物件的繪製成本。

## 熊熊居民

依照參考照片，以灰米色絨毛、藍橘印花、圓耳與黑色刺繡五官重建 3D 熊熊。居民會沿室內走道往返寢室與客廳，在幾個位置停下休息；路線避開實際家具與門框。

左下居民卡可暫停／開始散步、打招呼，以及切換跟隨熊熊的近景。也可直接點擊 3D 熊熊讓牠揮手。系統偏好減少動態效果時，預設停留休息，仍可手動開始散步。

`src/BearResident.jsx` 負責模型、程序絨毛／印花材質與動作；`src/residentMotion.js` 管理室內路線及步行狀態。照片是建模參考，沒有使用照片平面充當角色。

## 開發與建置

建議使用 Node.js 24（GitHub Actions 與測試使用此版本）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

開發網站位於 `/my-room/`。拖曳旋轉、滾輪縮放；下方導覽可切換全景、屋內、寢室、客廳、花園與露台。右側按鈕可切換標籤、庭園門、壁爐火光與重設視角。支援日夜模式及手機版，偏好減少動態效果時會停用視角過場。

`src/House.jsx` 負責家具和室內；`src/CottageDetails.jsx` 負責石牆、屋瓦、百葉窗、壁爐、法式門與藤編椅；`src/Garden.jsx` 負責花園與曲徑；`src/main.jsx` 負責頁面與互動。幾何、布料花紋與草地均由程式產生，無外部模型或 API 金鑰需求。

## GitHub Pages

`.github/workflows/deploy-pages.yml` 會在推送 `main` 後建置與部署。儲存庫的 **Settings → Pages → Source** 應選擇 **GitHub Actions**。

網站位置：https://skylinkeming.github.io/my-room/

## 生活小事

上方按鈕開啟留言板、共同清單和今天吃什麼。支援留言已讀、事項分類及勾選、餐點最愛與抽選、用餐紀錄。預設在本機瀏覽器保存，設定面板可設定名字及下載／匯入 JSON 備份。

兩支手機同步需自行建立 Supabase 專案，完整操作見 [設定說明](docs/supabase.md)，資料庫設定見 [SQL](supabase/setup.sql)。未完成設定前不會跨裝置同步。
