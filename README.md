# 日日小屋 · European Country Cottage

依照歐洲鄉村設計稿重建的 React + Three.js 互動小屋。首頁直接呈現可旋轉、縮放的 3D 模型，不使用設計稿圖片替代場景。

## 房屋與室內

- 正面石砌外牆保留，設有實際窗洞、木框分格玻璃窗與鼠尾草綠百葉窗。
- 兩側陶瓦屋簷、石砌煙囪和暖色壁爐；頂部保持剖面視角，能看見室內。
- 寢室包含雙人床、花布抱枕與窗簾、原木衣櫃、靠牆電腦桌和閱讀角。
- 客廳保留沙發、電視與茶几；廚房改為鄉村框板櫥櫃、窗下農舍水槽及開放層架。
- 客廳右側法式雙開玻璃門可開關，通往石鋪茶席露台。

## 花園

彎曲紅磚步道連接露台、玫瑰拱門和木柵門。繡球花、薰衣草與攀牆玫瑰集中在花境，中央保留草地。另有橄欖樹、木長椅、庭園小屋、藤編戶外座椅與茶几。原有日式溪流、拱橋、竹叢、枯山水與櫻花配置已移除。

花瓣、葉片、磚塊、石材與屋瓦使用實例繪製，減少大量重複物件的繪製成本。

## 開發與建置

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

開發網站位於 `/my-room/`。拖曳旋轉、滾輪縮放；下方導覽可切換全景、屋內、寢室、客廳、花園與露台。右側按鈕可切換標籤、庭園門、壁爐火光與重設視角。支援日夜模式及手機版，偏好減少動態效果時會停用視角過場。

`src/House.jsx` 負責家具和室內；`src/CottageDetails.jsx` 負責石牆、屋瓦、百葉窗、壁爐、法式門與藤編椅；`src/Garden.jsx` 負責花園與曲徑；`src/main.jsx` 負責頁面與互動。幾何、布料花紋與草地均由程式產生，無外部模型或 API 金鑰需求。
