# 日日小屋 · Little Warm Home

依據溫暖 Japandi 風格的室內設計稿製作，以 React、Three.js、React Three Fiber 與 Drei 呈現可旋轉的 3D 小屋與京都風環繞庭園。

- 寢室：景觀窗與雙層窗簾、綠色雙人床、床頭燈、整面衣櫃、靠牆電腦桌椅、書櫃與閱讀角。
- 客廳：杏桃色沙發、茶几、編織地毯、正對沙發的電視與電視櫃、邊桌與收納邊櫃。
- 開放式廚房與餐廳：鼠尾草綠櫥櫃、冰箱與烤箱、櫃下燈帶、四人餐桌及編織吊燈。
- 全高中央隔牆設有實際門洞；電視櫃避開門口，保留兩側通道。

## 設計稿與 3D 漫遊

首頁預設展示定稿原圖，可透過上方「設計稿／3D 漫遊」切換。設計稿是視覺參考圖片；3D 漫遊則是獨立建模、可旋轉與互動的風格化場景，兩者有清楚標示。選擇下方任一空間會進入對應的 3D 視角，含新增的櫻花近景。

## 櫻花庭園配置

庭園依最新版設計稿重新配置，約 52 × 46 個場景單位，為上一版庭園面積的約 2.7 倍。房屋維持約 16.2 × 13.2，中央與前方保留大片開闊草地。

- 左前方兩棵櫻花樹，以獨立枝幹、花簇及少量落花呈現，前後錯落。
- 左側僅保留一棵松樹、小片枯山水與一座石燈籠。
- 溪流集中右側，以疏落的自然石頭點綴，木橋連接兩岸。
- 客廳滑門通往木平台，踏石路穿越綠地到小橋，再通往右後方楓樹下的座椅。
- 衣櫃、靠牆電腦桌、閱讀角與開放式廚房保留。

流水使用程式 shader 呈現，右側可暫停；偏好減少動態效果的使用者預設停用流水與視角過場。

## 開發

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
```

拖曳旋轉、滾輪縮放；下方按鈕切換全景、屋內、寢室、客廳、庭園或櫻花近景。右上切換日夜，右側切換空間標籤、庭園門、流水動畫或重設視角。支援手機版。

## 建置

```sh
npm run build
npm run preview
```

`src/House.jsx` 包含房屋與家具模型；`src/Garden.jsx` 包含庭園、橋與流水；`src/main.jsx` 負責頁面、燈光與視角操作。3D 模式中的家具、木紋、布紋及庭園景觀均由程式產生，不需要外部模型、貼圖服務或 API 金鑰。設計稿模式使用 `public/design/sakura-garden.png` 作為視覺參考；可互動的 3D 場景為獨立的風格化實作。

## GitHub Pages 部署

網站發布位置為 https://skylinkeming.github.io/my-room/ 。Vite 的 `base` 已設定為 `/my-room/`，以便正確讀取 JavaScript、CSS 與其他資源。

在儲存庫的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。之後推送至 `main` 便會自動建置並部署，也可以從 **Actions → Deploy to GitHub Pages → Run workflow** 手動發布。部署成功後可在該次執行的 `github-pages` environment 查看網址。
